# MAGIC-ERP 系統設計：從 6 張 Excel 到單一資料庫

## 1. 現行人工流程的問題

| 原表單 | 填寫人 | 問題 |
|---|---|---|
| 2表 材料預算表 | 課程設計師 | 品名、規格每門課重複打字，同一物料常出現不同寫法，後續表格無法對應 |
| 3表 庫存清點表 | 倉儲 | 只有「某一天的數字」，兩次盤點之間的進出沒有紀錄，差異找不到原因 |
| 4表 庫存結餘表 | 倉儲 | 「預算 − 庫存」是人工抄寫兩張表再計算，最容易出錯；人數或排課一改就要重算 |
| 5表 產出清點表 | 倉儲 | 加工耗用多少原料、產出多少良品沒有回寫庫存 |
| 6表 共用器材表 | 授課人員 | 發現損壞後，是否補了、從哪裡補，沒有後續追蹤 |
| 7表 教室取物數量表 | 行政 | 每堂數量再從預算表人工換算一次；非耗材是否歸還無法追蹤 |

根本原因：**同一份資料被抄寫在多張表**，而**庫存是「填」出來的，不是「算」出來的**。

## 2. 設計原則

1. **主檔只登記一次**：物料、課程、教室、班級各有一份主檔，其他單據只引用代號。
2. **庫存＝異動加總**：所有進出（入庫、盤點調整、加工、領料、歸還、撥補、報廢）都寫入「庫存異動帳」，現有庫存隨時由系統加總，不再人工填結餘。
3. **計算交給系統**：課堂需求、採購建議、加工建議、領料數量都由「每堂用料 × 班級人數」自動推算。
4. **單據有狀態**：加工單、領料單、盤點單都有明確流程與負責角色，誰做了什麼都有紀錄。

## 3. 物料分類（取代「耗材 / 非耗材」單一欄位）

| 類別 | 說明 | 庫存行為 | 需求計算 |
|---|---|---|---|
| 耗材 consumable | 上課用完即消耗（木板、電池、膠） | 領料即扣庫存；剩餘可退回 | 期間內各堂需求**加總** |
| 非耗材 reusable | 從倉庫領出上課、課後歸還（工具、電表） | 領料扣庫存、結案歸還加回 | 取**單日最高同時用量** |
| 共用器材 shared | 常駐教室的教具（熱熔膠槍、切割墊） | 倉庫庫存只代表備品；撥補教室時扣庫存 | 依「教室標準配置 − 盤點良品」 |

**需加工品**：在物料上設定「加工原料」與「原料耗用比」（例：1 片 60×30 大板裁 8 片 15×15 小板 → 耗用比 0.125）。需求分析會把加工品缺口自動換算成原料需求。

## 4. 新舊對照

| 原表單 | 新系統模組 | 做法 |
|---|---|---|
| 2表 材料預算表 | **課程用料** | 課程 → 堂次 → 每堂用料（用量 + 基準：每人 / 每組 / 每班 + 損耗率），並提供整門課預算試算 |
| 3表 庫存清點表 | **盤點** | 建盤點單時凍結帳面數 → 輸入實盤數 → 過帳自動產生差異調整 |
| 4表 庫存結餘表 | **需求分析**（自動） | 選日期區間 → 系統算出課堂需求、可用量、建議採購 / 加工數量，可匯出 CSV |
| 5表 產出清點表 | **加工單** | 待加工 → 加工中（扣原料）→ 待確認（回報良品）→ 已入庫（倉儲確認） |
| 6表 共用器材表 | **教室器材** | 教室標準配置 + 授課人員定期盤點（良品 / 損壞 / 遺失）→ 自動算出需補 → 倉儲一鍵撥補 |
| 7表 教室取物數量表 | **領料單** | 依排課自動產生每「堂」領料單 → 發料扣庫存 → 課後結案歸還 |

## 5. 角色與權限

| 角色 | 主要工作 | 可寫入的模組 |
|---|---|---|
| 課程設計師 | 設計課程、設定每堂用料 | 物料主檔、課程用料 |
| 倉儲人員 | 進貨、盤點、加工、撥補器材 | 物料主檔、庫存、盤點、加工、領料發料、器材撥補 |
| 授課人員 | 教室器材盤點、課後歸還 | 教室器材盤點、領料結案 |
| 行政人員 | 開班排課、產生領料單 | 教室、開班排課、領料單 |
| 系統管理員 | 帳號管理 | 全部 |

所有角色都可以**查看**全部資料（例如授課人員可以看到下週的領料單內容）。

## 7. 資料模型

```
users
materials ──┐ (source_material_id 自我參照：加工品 → 原料)
            │
courses ─< lessons ─< lesson_materials >─ materials           （課程用料／2表）
classrooms ─< classroom_equipment >─ materials                 （標準配置／6表）
classrooms ─< equipment_checks ─< equipment_check_lines        （器材盤點／6表）
courses, classrooms ─< class_groups ─< sessions >─ lessons      （開班 / 每一堂）
sessions ─ pick_lists ─< pick_lines >─ materials                （領料單／7表）
process_orders >─ materials                                     （加工單／5表）
stocktakes ─< stocktake_lines >─ materials                      （盤點單／3表）
stock_moves >─ materials        ← 所有模組的庫存變動都寫到這裡（4表由此計算）
```

完整欄位見 `magic_erp/schema.sql`。

## 8. 核心計算

**每堂用量**
```
倍數 = 學生數（每人） | ⌈學生數 ÷ 每組人數⌉（每組） | 1（每班）
需求 = ⌈用量 × 倍數 × (1 + 損耗率)⌉
```

**需求分析（取代 4表）**，針對期間內「已排定、未領料」的課堂：
```
課堂需求   = 耗材：各堂加總；非耗材：單日最高用量
可用量     = 現有庫存 + 領出未還（非耗材）+ 加工中預計產出 − 待加工單保留的原料
建議數量   = max(0, 課堂需求 + 加工衍生需求 + 安全存量 − 可用量)
建議動作   = 有原料設定 → 開加工單（並把 建議數量 × 耗用比 加到原料的「加工衍生需求」）
             否則 → 採購
```

**盤點差異**：過帳時調整量＝實盤數 − 建單當下帳面數，盤點期間發生的進出不會被抹掉。

## 9. 從 Excel 移轉

1. 將「材料預算表」中所有不重複物料整理成一張表，欄位：`料號,品名,規格,單位,類別,安全存量,期初庫存`（類別填 耗材 / 非耗材 / 共用器材，期初庫存可用最近一次「庫存清點表」），另存 CSV（UTF-8），於「物料主檔」頁面匯入。
2. 需加工的物料在物料頁設定原料與耗用比、加工流程。
3. 課程設計師在「課程用料」把每門課每堂的用料輸入一次。
4. 行政在「教室器材」建立教室並設定標準配置（取自「共用器材表」），在「開班排課」建立班級。
5. 之後只需日常作業，不必再維護結餘表與取物數量表。
